# Описание проекта - Исследование оттока клиентов в банке

## Данные:

Для исследования оттока клиентов в банке использовались следующие данные:
— идентификатор пользователя,
— баллы кредитного скоринга,
— город,
— пол,
— возраст,
— количество баллов собственности
— баланс на счёте,
— количество продуктов, которыми пользуется клиент,
— есть ли кредитная карта,
— активный клиент,
— оценочный доход клиента,
— признак оттока.



  ## Задача:

  На основании анализа оттока клиентов определить признаки отточности и выделить сегменты клиентов для повышения эффективности работы банка с клиентами и как следствие увеличения доходов банка.

  ## Используемые библиотеки

  *pandas*, *matplotlib*, *seaborn*, *statistics*
